# JFFS2Reader
Программа для чтения и извлечения файлов из JFFS2

В интернетах полно распаковщиков jffs на питоне, которые в нужный момент не работают, а готовых программ на нормальном языке не хватает.

С гуглом, дипсиком и клауде исправили эту несправедливость и написали программу для открытия jffs. 

Изначально программа писалась для прикола, чисто посмотреть, можно ли сделать такое на паскале, проверялась на файловой системы прошивки модема йоты, другие файлы пока открывать не пробовал.

Собсна, первая версия умеет открывать образ jffs, и извлекать из него файлы. Показывает текстовые файлы и картинки.
